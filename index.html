Curso CSS (Basico)

CSS es un lenguaje para diseñar las paginas webs y siempre esta a la par de HTML.

Hoy veras algo nuevo sobre CSS pero antes hay que repasar cosas sobre HTML.

En HTML hay cosas importantes para CSS, una de ellas es class="nombre-de-la-clase" que se encuentran adentro de etiquetas.

Un ejemplo puede ser: <p class="clasecss">Este texto tiene una clase</p>.

La utilidad de las clases en CSS es poder darle estilo a todo elemento que este en HTML con la misma clase.
Pero antes de adentrarnos a las clases hay que saber como crear y usar un CSS.

En Visual Studio Code en tu carpeta debes crear un archivo con extensión .css y vincularlo al archivo HTML.
(Los nombres recomendables para poner a tu carpeta son: index.html y styles.css)

Despues de crear el CSS debes vincularlo al archivo HTML.
Para lograr eso debes entrar a tu HTML y agregar la etiqueta <link rel="stylesheet" href="nombredelCSS.css"> dentro de la sección <head>.

Para tener un contenido mas completo, puedes abrir este PDF: Curso CSS (Básico)

Ahora sabiendo esto vamos a aprender la sintaxis de CSS.

Para aplicar estilos al HTML, se debe llamar la etiqueta o clase que se va a decorar y entre llaves {} se definen los estilos.
Adentro de las llaves se llama por el nombre a la propiedad y despues de : el valor de la propiedad. (todo valor debe terminar con ;)

Aca hay un ejemplo de como se cambia el color a un texto con la etiqueta <p>:

background-color

Ahora sabiendo la sintaxis de CSS, podemos empezar sabiendo la propiedad background-color.

Esta propiedad sirve para cambiar el color de fondo de un elemento.
Se puede usar para cambiar el color de una pagina o otros elementos que veremos mas tarde.

Para usar esta propiedad se debe escribir background-color seguido de dos puntos : y luego el valor del color que se quiere usar, para finalizar se debe poner un punto y coma ;

Ejemplo: background-color: red;

Se puede determinar el color de formas diferentes

  • Por nombre: background-color: red;
  • Por código hexadecimal: background-color: #ff0000;
  • Por valores RGB: background-color: rgb(255, 0, 0);

Tambien se puede cambiar el color mediante un menu que tiene el CSS en Visual Studio Code.

font-family y font-size

La propiedad font-family sirve para cambiar el tipo de letra de un texto.
Se pueden usar tipos de letras que ya existen o tambien se pueden usar tipos de letras descargados.

Para usar esta propiedad se debe escribir font-family seguido de dos puntos : y luego el nombre del tipo de letra que se quiere usar, para finalizar se debe poner un punto y coma ;

Ejemplo: font-family: Arial;

Hay fuentes precargadas en Visual Studio Code pero se puede usar fuentes descargadas, ya sea de Google Fonts o por el internet.

La propieda de font-size sirve para cambiar el tamaño de la letra de un texto.
La sintaxis del font-size es: font-size: tamaño;

El tamaño lo determina el usuario ya que hay diferentes medidas para el tamaño del texto.
Las medidas mas usadas son:

  • Medida en pixeles: font-size: 16px;
  • Medida en porcentaje: font-size: 100%;
  • Medida en em: font-size: 1em; (em es una unidad de medida relativa al tamaño de la fuente)

color

La propiedad color sirve para cambiar el color del texto.
Se puede usar para cambiar el color de una pagina o otros elementos que veremos mas tarde.

La sintaxis de color es: color: valor;
El valor puede ser los mismos a los de background-color
